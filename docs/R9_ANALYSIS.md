# B11 r9-large 解释报告：为什么 large 首超 beam、small 却显著回退

> 2026-11-23。配套 [EXPECTIMAX「B11 r9-large」](EXPECTIMAX.md)（结果与门判定）。
> 本报告回答：r9 = v6 配方 + large 自对弈数据（单变量），为什么 large +29.6 而 small −0.42？
> 全部证据来自离线确定性探针（无重训）：训练信号分解 / 模型标准化参数对比 /
> 决策级行为比较（`data/_r9_behavior_probe.py` → `out/_r9_behavior_probe.json`）。

## 0. 结论先行

**r9 不是「学坏了」，是「学偏了」——共享权重把优化预算重新分配给了 large。**
三个叠加通道：

1. **标签信号稀释（主因）**：全局 std 归一化下，small 自对弈的优化能量份额从
   v6 的 **91.8% 崩到 20.9%**（large 占 70.9%）；small 标签归一化后 std 1.000→0.653；
2. **输入侧漂移**：混合数据把「场景身份维度」（CLEAR/PERFECT 目标、体力上限、总回合、
   牌库聚合）从常量变成真实特征，small 状态在特征空间被重新映射，v6 学到的 small
   精细行为要在**新位置**重新学，而预算只剩 1/5；
3. **v1 示范拉扯（放大项）**：示范行数 25695→48101（×1.87，为解锁 0.15 占比上限），
   软目标 ±1 相对稀释后的小标签更强，且 v1 打法比 v6 更偏即时分——r9 在 small
   分歧点的行为偏移方向恰与 v1 风格一致。

结果：**large 学到正确的长 horizon 耐心（早回合 buff，+28.6，24 个 CLEAR 翻正）；
small 丢失 v6 的精细耐心（分歧点更贪即时分，5 个 CLEAR 翻负，−0.42）**。
数据量/容量/训练量都不是问题——large 的巨大增益证明学习本身有效。

## 2. 证据 A：训练信号能量分解

优势标签训练前按**全局 std** 归一化（单文件同口径）。MSE 梯度早期 ∝ 标签残差，
标签能量（Σy²）是优化影响力的合理代理（**注意：这是代理指标，不是梯度精确分解**）：

| 口径 | small 自对弈 | large 自对弈 | 示范 |
|---|---:|---:|---:|
| **v6**（small std 12.21 归一） | **91.8%** | — | 8.2% |
| **r9**（混合 std 18.71 归一） | **20.9%** | **70.9%** | 8.2% |

- 归一化后标签 std：v6 small = 1.000；r9 small = **0.653** / large = 1.288；
- 原始 std：small 12.21 / large 24.09（large 分数尺度 ~300 vs small ~100，优势天然更大）；
- 示范能量份额两轮都是 8.2%，但**绝对行数 25695→48101**（r4 28934 + 新采 23050
  下采样）——相对 small 自对弈标签（缩到 65%），示范 ±1 的相对权重近乎翻倍。

**含义**：r9 的优化预算约 7 成给了 large；small 行为要在被稀释的信号下重新维持。

## 3. 证据 B：输入侧标准化漂移

`train_policy_mlp` 对 X 做逐维 (x−mean)/scale（scale<1e-8 → 1.0）。
v6 只见 small → 场景身份维度是**常量**（scale 退化为 1.0）；r9 见 small+large →
这些维度变成真实特征，mean/scale 剧变（|Δmean|/v6scale 最大的维度）：

| dim | 特征 | v6 mean→r9 mean | v6 scale→r9 scale |
|---:|---|---|---|
| 16 | perfect（目标） | 170 → 280.7 | 1.0 → 136.9 |
| 15 | clear（目标） | 120 → 191.2 | 1.0 → 88.0 |
| 7 | stamina_max | 34 → 44.3 | 1.0 → 12.7 |
| 1 | total_turns | 5 → 6.58 | 1.0 → 1.96 |
| 54 | pool_count | 14 → 20.7 | 1.0 → 8.3 |
| 59 | deck_score_sum | 44.9 → 95.3 | 24.4 → 83.0 |
| 82/94/96/120 | condition×deck / full_power_scale | 0 → 非零 | 1.0 → 3.7–57.7 |

**含义**：v6 的 small 行为学在「clear/perfect 归一化 = (−50, 0)、turns=5、stamina=34」
这个**固定点**上；r9 里 small 状态被映射到 (−0.81, −0.24)、turns≈5/9 混合、stamina 34/60
混合的**新位置**，且网络现在可以用这些维度区分场景。共享权重要在新位置重新表达
small 行为——而证据 A 说预算只剩 20.9%。**这是「场景条件化」的代价：v6 不会区分场景
（不需要），r9 必须区分，但 small 那一侧没学充分。**

## 5. 机制综合

```
large 数据进入混合
  ├─ 标签能量：small 91.8% → 20.9%（全局 std 18.71 稀释）
  ├─ 输入漂移：场景身份维度常量 → 特征，small 状态重映射
  └─ 示范 ×1.87（v1 风格，偏即时分）相对权重上升
        ↓
共享 192×96 权重重新分配优化预算
  ├─ large（70.9% 能量）：学到早回合 buff 耐心 → +29.6，超 beam
  └─ small（20.9% 能量 + 新特征位置）：v6 精细耐心维持不足
        → 67 局分歧、更贪即时分（v1 方向）、5 个 CLEAR 翻负 → −0.42
```

**排除的替代假设**：
- 容量/训练量不足：同 192×96/1200ep，large 巨大增益证明拟合有效；
- 数据量本身有害：large 侧数据越多越好（+29.6），问题在**相对信号强度**不在绝对量；
- 种子段结构 / harness 漂移：同 500 seed 配对 CI + 新鲜块 + 选择段同向；参照臂逐位一致；
- 「small 全量保留就能防回退」：保留了**数据行**，但没保留**信号份额与特征位置**——
  这是本轮最重要的方法论教训：**混合训练防回退，保行数不够，要保归一化口径**。

**判定（回答 P1-1① 的问题）**：

1. **残留 small 回退已不是 v1 风格贪即时分为主**。r9 的系统性贪即时分偏置（24:9）在 r10
   收窄到接近均衡（11:8）；r10 对 v1 的耐心比（25:11）已恢复到 v6 水平（29:13），而 r9
   当时被拉到接近 v1（18:17）。通道 3（v1 示范拉扯）的行为特征被归一化修复大幅消除。
2. **残留 −0.256 是无方向决策噪声，不是方向性策略拉扯**：53 个分歧局里首分歧方向混合

   这与通道 2（输入侧场景漂移：共享权重在重映射特征位置重新表达 small 精细行为）的
   预期一致——§8 的「输入侧漂移仍在」得到行为级佐证。
3. **large 增益机制保持**（早回合铺 buff、0 次贪即时分分歧），与 §8「large 保持」一致。

**对 r11 的含义**：候选②（small 上采样，能量 →~66%）仍是设计内对症变量——给 small

（行为证据显示拉扯已大幅消退），若 r11 仍差再作叠加变量考虑。

**结论**：候选②（small 上采样）+ ①（按场景归一化）叠加**修复了通道 2 的残留 small 回退**——
small 能量份额 49%→65.6% 给足优化预算，共享权重在重映射后的特征位置重新学准 small 精细行为，
small 恢复到 v6 水平（不回退），同时 large 增益保持（+26.1，超 beam +12.3）。**复合门首次双过 →
入库**（生产 ei_policy_v6.json = r11 权重）。

**与 §9 行为探针的一致性**：§9 判定残留回退是「无方向决策噪声」（通道 2），非 v1 拉扯（通道 3）——
r11 用「给 small 更多预算」（对症通道 2）而非「换教师」（通道 3）修复成功，验证了 §9 的机制诊断。
教师仍 v1@0.15（基础池），未动通道 3（单变量纪律：r11 相对 r10 的变量 = 上采样 + 新规则数据）。

**新旧对比（P2-1b，分清规则分移 vs 学生改进）**：small 规则零分移（所有臂 Δ=0）；large 规则分移 ±2
（v6 +1.98 / r9 −1.98 / r10 −1.28）。large headline「r11 vs 旧 v6 +28.08」= **学生改进 +26.10（93%）
